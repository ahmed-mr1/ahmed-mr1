## 🚀 Featured Project — TBS Portal

**[TBS Portal](https://tbsportal.tn/)** is a student platform for Tunis Business School that centralizes academic services in one place. It is used by **1,400+ students** and has been running in production for almost a year.

- 📅 Smart schedules, contacts, club management and a **Study Hub with 400+ resources**
- 🤖 **RAG chatbot** that answers from the university's official documents, with cited sources, in Arabic, French and English
- 🔎 **Azure OCR** to extract timetables and exam schedules from documents automatically
- ☁️ Fully hosted on **Azure**: App Service, PostgreSQL Flexible Server, Blob Storage
- 🔄 **CI/CD** with GitHub Actions for automated deployment

**Stack:** FastAPI · PostgreSQL + pgvector · Next.js · TypeScript · Azure OpenAI · GitHub Actions

### 👗 Verdrobe
A second-hand clothing marketplace built during my internship at [Smart for Green](https://smartforgreen.com). Buyers enter their body measurements, sellers list garments with detailed measurements, and an **AI fit recommendation** shows a **heatmap on a 3D body** (tight, loose or a perfect fit). The 3D body is generated from the measurements with the **Anny** library.

Verdrobe promotes the reuse of second-hand clothing, and accurate fit recommendations aim to reduce size-related returns and textile waste.
